Telegram-бот для уведомлений о выходе новых серий
Описание проекта:

Автоматическая система оповещения пользователей о выходе новых эпизодов любимых сериалов. Пользователь подписывается на сериал → бот периодически проверяет расписание выхода через внешние API → при появлении новой серии отправляет уведомление в Telegram.

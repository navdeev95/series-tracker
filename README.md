# 🎬 Series Notification Bot

Telegram-бот для автоматического оповещения о выходе новых серий любимых сериалов.

## 📌 Описание

Пользователь подписывается на сериал → бот периодически проверяет расписание выхода через внешние API → при появлении новой серии отправляет уведомление в Telegram.

## 🛠 Технологический стек

| Компонент | Технологии |
|---|---|
| Язык | Java 17 |
| Фреймворк | Spring Boot |
| ORM | Hibernate |
| База данных | PostgreSQL |
| Миграции | Liquibase |
| Тестирование | JUnit, Mockito |
| Сборка | Maven |
| Логирование | SLF4J + Logback |
| Внешние API | TMDB API, Kinopoisk API, MovieLab API |
